# Triage Labels

Skills 内部统一使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库 tracker 的标签 | 含义                   |
| -------------------------- | --------------------- | ---------------------- |
| `needs-triage`             | `needs-triage`        | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`          | 等待报告者补充信息     |
| `ready-for-agent`          | `ready-for-agent`     | 规格完整，可交给 agent |
| `ready-for-human`          | `ready-for-human`     | 需要人来实现           |
| `wontfix`                  | `wontfix`             | 不会处理               |

当 skill 提到某个角色时（例如 "apply the AFK-ready triage label"），使用上表中对应的标签字符串。

如果实际使用的标签词汇不同，改 "本仓库 tracker 的标签" 这一列来匹配。
